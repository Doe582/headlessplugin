       - payment_method_title (string, optional): Payment method title
       - shipping_method (string, optional): Shipping method

       - status (string, optional): Order status

       - customer_note (string, optional): Customer note

8. SHIPPING ZONES API
--------------------------------------------------------------------------------

GET    /shipping/zones (requires auth)
       Parameters: None
       Description: Get all shipping zones including "Rest of the World" zone
       Response: Returns array of zones with id, name, order, locations, methods, method_count

GET    /shipping/zones/{id} (requires auth)
       Parameters: None
       Description: Get a specific shipping zone by ID
       Response: Returns zone object with id, name, order, locations, methods, method_count

POST   /shipping/zones (requires auth)
       Body Parameters:
       - zone_name (string, required): Zone name (e.g., "US Shipping", "Europe Zone")
       - zone_order (integer, optional): Zone display order (default: 0)
       - locations (array, optional): Zone locations
         Each location object:
         - code (string, required): Location code
         - type (string, required): Location type
           Types: "country", "state", "postcode", "continent"
         Examples:
           - Country: {"code": "US", "type": "country"}
           - State: {"code": "US:CA", "type": "state"} or {"code": "CA:BC", "type": "state"}
           - Postcode: {"code": "90210...90215", "type": "postcode"}
           - Continent: {"code": "EU", "type": "continent"}
       Description: Create a new shipping zone
       Response: Returns created zone object with status 201

PUT    /shipping/zones/{id} (requires auth)
       Body Parameters: (all optional, only include fields to update)
       - zone_name (string, optional): Update zone name
       - zone_order (integer, optional): Update zone order
       - locations (array, optional): Update zone locations (replaces all existing)
         Same format as POST locations
       Description: Update an existing shipping zone
       Response: Returns updated zone object

DELETE /shipping/zones/{id} (requires auth)
       Parameters: None
       Description: Delete a shipping zone
       Response: Returns {"deleted": true, "id": zone_id}

GET    /shipping/zones/{zone_id}/methods (requires auth)
       Parameters: None
       Description: Get all shipping methods in a specific zone
       Response: Returns object with zone_id, methods array, and total count

POST   /shipping/zones/{zone_id}/methods (requires auth)
       Body Parameters:
       - method_id (string, required): Shipping method ID
         Available methods: "flat_rate", "free_shipping", "local_pickup", "international_delivery"
       - settings (object, optional): Method instance settings
         For flat_rate:
           - title (string, optional): Method title (e.g., "Standard Shipping")
           - cost (string, optional): Shipping cost (e.g., "10.00")
           - tax_status (string, optional): "taxable" or "none"
           - class_cost (string, optional): Cost per shipping class
           - no_class_cost (string, optional): Cost when no shipping class
           - type (string, optional): "class" or "order"
         For free_shipping:
           - title (string, optional): Method title
           - requires (string, optional): "coupon", "min_amount", "either", ""
           - min_amount (string, optional): Minimum order amount (e.g., "100.00")
         For local_pickup:
           - title (string, optional): Method title
           - tax_status (string, optional): "taxable" or "none"
           - cost (string, optional): Pickup cost (usually "0.00")
       Description: Add a shipping method to a zone
       Response: Returns success, instance_id, and method object with status 201

GET    /shipping/zones/{zone_id}/methods/{instance_id} (requires auth)
       Parameters: None
       Description: Get a specific shipping method instance in a zone
       Response: Returns method object with instance_id, method_id, method_title, title, enabled, settings

PUT    /shipping/zones/{zone_id}/methods/{instance_id} (requires auth)
       Body Parameters: (all optional, only include fields to update)
       - enabled (boolean, optional): Enable/disable method (true/false)
       - title (string, optional): Update method title (top-level, not in settings)
       - settings (object, optional): Update method instance settings
         Same settings as POST /methods (flat_rate, free_shipping, local_pickup)
         Examples:
           Flat Rate: {"enabled": true, "settings": {"cost": "15.00", "title": "Express", "tax_status": "taxable"}}
           Free Shipping: {"enabled": true, "settings": {"min_amount": "150.00", "requires": "min_amount"}}
           Local Pickup: {"enabled": false, "title": "Store Pickup"}
       Description: Update a shipping method instance in a zone
       Response: Returns success and updated method object

DELETE /shipping/zones/{zone_id}/methods/{instance_id} (requires auth)
       Parameters: None
       Description: Remove a shipping method from a zone
       Response: Returns {"deleted": true, "instance_id": instance_id}

GET    /shipping/methods (requires auth)
       Parameters: None

================================================================================
AUTHENTICATION
================================================================================

Most POST, PUT, DELETE endpoints require authentication.

Authentication Methods:
1. Application Passwords (recommended)
2. Cookie authentication (for logged-in users)
3. Bearer token (if using custom auth)

To get Application Password:
1. Go to WordPress Admin → Users → Your Profile
2. Scroll to "Application Passwords"
3. Enter name and click "Add New Application Password"
4. Copy the generated password

cURL Example with Authentication:
curl -X POST "http://localhost/wooautopublix/wp-json/restbridge/v1/posts" \
  -u "username:application_password" \
  -H "Content-Type: application/json" \
  -d '{"title": "New Post", "content": "Content"}'

JavaScript Example:
fetch('http://localhost/wooautopublix/wp-json/restbridge/v1/posts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Basic ' + btoa('username:application_password')
  },
  body: JSON.stringify({title: 'New Post', content: 'Content'})
})

================================================================================
NOTES
================================================================================

1. All endpoints use namespace: restbridge/v1
2. Replace "localhost/wooautopublix" with your actual domain
3. Most POST/PUT/DELETE endpoints require authentication
4. GET endpoints are generally public (except users, orders, reports, settings)
5. Query parameters are passed as URL parameters (e.g., ?per_page=10&page=2)
6. POST/PUT request bodies should be JSON with Content-Type: application/json
7. Cart endpoints use WooCommerce session cookies (no auth required)
8. All dates should be in YYYY-MM-DD format
9. All prices/amounts should be numeric or string format (e.g., "10.00")
10. For file uploads (media), use multipart/form-data
